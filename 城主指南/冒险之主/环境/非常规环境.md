#### 游泳<span lang="EN-US">Swimming</span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>除非有魔法帮助，否则一名角色每天不能进行超过<span lang="EN-US">8</span>小时的游泳活动。游泳时间每经过<span lang="EN-US">1</span>小时，该角色就必须成功通过一次<span lang="EN-US">DC 10</span>的体质豁免，否则将提升一等级的力竭。<span lang="EN-US">  
<span style="mso-spacerun:yes"> </span></span>有游泳速度的角色（包括着装*善泳指环<span lang="EN-US">ring of swimming</span>*或带有相似魔法效应的角色）可以不带疲惫风险的进行一整天的游泳活动，不过依然要遵照*《玩家手册》*中关于强行军的规则。<span lang="EN-US">  
<span style="mso-spacerun:yes"> </span></span>因水压和寒冷水温的影响，在深水区游泳时的情况类似在高海拔地区旅行。没有游泳速度的生物在超过<span lang="EN-US">100</span>尺水深区域时，每游泳<span lang="EN-US">1</span>小时视为已经游泳<span lang="EN-US">2</span>小时来确定力竭等级。而在<span lang="EN-US">200</span>尺水深区域时，每经过<span lang="EN-US">1</span>小时则视为<span lang="EN-US">4</span>小时看待。<span lang="EN-US"></span>

#### 导航<span lang="EN-US">Navigation</span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>航海载具航行时会尽量接近海岸，这样可以利用可见地标使导航更容易进行。只要船上能看到陆地，航路就不会迷失。如果看不到陆地，船队的领航员就必须依靠航行轨迹来推断船队的位置（通过跟进船方向和航行距离）。条件允许时，也可以利用天上的星星和太阳进行定位。<span lang="EN-US">

#### 海上天气<span lang="EN-US">Weather at Sea</span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>参照本章早前所述的表格“天气”来确定海上的天气状况。<span lang="EN-US">  
<span style="mso-spacerun:yes"> </span></span>在天气状况的检定同时出现强风和大雨时，天气将视为两者结合导致的风暴和巨浪。船员们在风暴中将失去所有可做导航的陆上地标（灯塔和其他有明亮特征的地标除外），并且在风暴中用以导航的所有属性检定都具有劣势。<span lang="EN-US">  
<span style="mso-spacerun:yes"> </span></span>风平浪静时（没有风）船只无法扬帆起航，而船队只能通过划船作业继续前进。此外，船只在强风天气逆风行驶时只能以一半的速度航行。<span lang="EN-US"></span>

#### 能见度<span lang="EN-US">Visibility</span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>平静天气时的大海可以提供很好的能见度。这时从船只的t望台上可以看到<span lang="EN-US">10</span>里外的另一艘船或海岸线。阴天会使能见距离减少一半。雨雾天气的能见度则跟陆上旅行时一样。<span lang="EN-US"></span>

#### 拥有一艘船<span lang="EN-US">Owning a Ship</span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>某些时候，冒险者可能会获得船舶的所有权。他们可能花钱购买，或在战斗中俘获，又或者直接从任务中接收船舶。你可以决定冒险者的船是否可以购买，也可以随时设法剥夺角色对船舶的所有权，比如当船舶的所有权妨碍故事发展时就可以考虑这么做。（参考“船难”边栏）。<span lang="EN-US"></span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>***<span style="font-family:黑体;mso-ascii-font-family:
宋体;mso-hansi-font-family:宋体;mso-bidi-font-family:Arial">船员</span>**<span lang="EN-US" style="mso-fareast-font-family:
黑体;mso-bidi-font-family:Arial">Crew</span>**<span style="font-family:黑体;mso-ascii-font-family:宋体;mso-hansi-font-family:
宋体;mso-bidi-font-family:Arial">。</span>***一艘船需要一队熟练的雇工才能实现使它航行的职能。按照*《玩家手册》*的描述，一名熟练的雇工每日必需花费<span lang="EN-US">2 gp</span>。雇佣熟练船工的最小花费视所使用的载具类型决定，这在表格“空运及水运载具”中有详细的描述。<span lang="EN-US">  
<span style="mso-spacerun:yes"> </span></span>计算船员的忠诚度时，你可以视每位船员为独立个体，或者将所有船员作为一个整体看待。关于忠诚度的选项可以使用第<span lang="EN-US">4</span>章的规则。当非忠诚状态的船员达到半数时，船员们将变为敌对并发动叛乱。如果叛乱时船只正处于停泊状态，非忠诚的船员将离开船队，并永远不再回来。<span lang="EN-US"></span>

<span style="mso-spacerun:yes"> </span></span>尽管各船之间床位的价格并不一定一致，但乘客通常会为一张吊床床位支付每天<span lang="EN-US">5 sp</span>的租金，而私人房间的床位则可以收取每天<span lang="EN-US">2 gp</span>的租金。<span lang="EN-US"></span>

#### <span style="font-size:10.5pt;mso-ascii-font-family:Calibri;mso-hansi-font-family:
Calibri;color:black;mso-themecolor:text1">船难</span><span lang="EN-US" style="font-size:10.5pt;font-family:&quot;Calibri&quot;,sans-serif;mso-bidi-font-family:

<span lang="EN-US" style="font-size:10.0pt;mso-bidi-font-size:

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>飞行中的角色在地点间移动时，可以直接按直线航行，并忽略一切地形因素，以及非飞行怪物威胁和非远程的攻击。<span lang="EN-US">  
<span style="mso-spacerun:yes"> </span></span>按照*《玩家手册》*的描述，通过法术或者魔法物品运作的飞行旅行，将按步行旅行的规则一样运作。作为飞行坐骑的生物每飞行<span lang="EN-US">3</span>小时必须进行<span lang="EN-US">1</span>小时的休息，并且每天不能进行超过<span lang="EN-US">9</span>小时的飞行作业。按这个规则举例，角色骑着狮鹫<span lang="EN-US">griffon</span>（拥有<span lang="EN-US">80</span>尺飞行速度）旅行，每小时可以飞行<span lang="EN-US">8</span>里，一天进行<span lang="EN-US">9</span>小时飞行总计可以飞行<span lang="EN-US">72</span>里，期间必须进行两次<span lang="EN-US">1</span>小时时长的休息。不会疲倦的坐骑（比如飞行构装生物）不受这个规则所限。<span lang="EN-US"></span>

<span lang="EN-US"><span style="mso-spacerun:yes"> </span></span>冒险者们飞越天空时，随机遭遇的检定频率跟一般情况相同。飞行中的角色忽略所有不可飞行生物的影响，除非角色正贴近地面飞行且可作为该生物的远程攻击目标。飞行中的角色可以随意指定地面上的生物为目标，随时与该目标进行交互。<span lang="EN-US"></span>
