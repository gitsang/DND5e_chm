**<span style="FONT-SIZE: 18pt; FONT-FAMILY: 黑体; COLOR: rgb(128,0,0); mso-ascii-font-family: 'Times New Roman'; mso-hansi-font-family: 'Times New Roman'">大魔鬼的护咒 Archdevil Charms</span>**

<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">护咒是《城主指南》第七章中描述的超自然赠礼。大魔鬼和他们指定的家臣可以赐予凡人这样的赠礼，通常是为了诱使他们签下一个地狱契约。这一节描述了大魔鬼和他们的家臣可以赐予一些新的护咒。</span>

**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(128,0,0)">长生不老护咒 Charm of Agelessness</span>**

<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">当你拥有这种护咒时，你不会自然衰老，你的皮肤会获得洋娃娃般的蜡质。然而，魔法衰老仍然会影响你。当你死亡时，该护咒会从你身上消失。</span>

**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(128,0,0)">邪魔激励护咒 Charm of Diabolical Inspiration</span>**

<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">当你获得这个护咒时，你会长出一条短而发育不良的尾巴，除非你已经具有一条尾巴。当你进行属性检定、攻击检定或豁免检定时，你可以使用此护咒在检定中获得优势。使用九次之后，该护咒会从你身上消失，你的残尾也随之消失。</span>

**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(128,0,0)">高等征召护咒 Charm of Greater Conscription</span>**

<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">当你拥有这种护咒时，你会吸引苍蝇。作为一个动作，你激活这个护咒并召唤一个</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(0,0,0)">角魔horned devil</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">。这个魔鬼出现在一个距你30尺内的未占据空间，不情愿地服从你的命令，在抗议中服侍你九天，或者直到它死去，然后魔鬼消失。当魔鬼消失的时候，该护咒会从你身上消失。</span>

**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(128,0,0)">炼狱叱喝护咒 Charm of Hellish Rebuke</span>**

<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">当你获得这个护咒时，在你的头上出现了一个火焰光环。这个护咒允许你用一个反应施放</span>*<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0); FONT-STYLE: italic">炼狱叱喝hellish rebuke</span>*<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">（以9环形式）。使用九次之后，该护咒会从你身上消失，火焰光环也一样。</span>

**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(128,0,0)">次级征召护咒 Charm of Lesser Conscription</span>**

<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">当你拥有这种护咒时，你会吸引苍蝇。作为一个动作，你激活这个护咒并召唤一个</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(0,0,0)">猬魔barbed devil</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">或两个</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(0,0,0)">须魔bearded devil</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)">或三个</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 黑体; COLOR: rgb(0,0,0)">棘魔spined devil</span>**<span style="FONT-SIZE: 12pt; FONT-FAMILY: 宋体; COLOR: rgb(0,0,0)"></span>
